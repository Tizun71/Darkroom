# Security policy

## Reporting a vulnerability

Do not open a public issue for security problems.

Report them privately through GitHub: open the **Security** tab of this repository and click **Report a vulnerability**. Include the steps to reproduce and the affected URL or file.

You get a first reply within 7 days. After a fix ships, the report is published as a security advisory, with credit to you if you want it.

## Scope

This is a static site with no backend and no user accounts. Relevant reports include XSS through content in `content/`, problems in the build scripts, and vulnerable dependencies.
